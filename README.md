# Notes_App

A new Flutter project of my bootcamp. It contains two pages 
1. First page is to list all the notes.
2. Second page is a new notes added page.

## Features
 1. List all notes in Home Page
 2. Create a new note
 3. Update your old Note
 4. Dynamic UI with real-time update using Statefulwidgets
